# Bank Account Management System

An object-oriented Python implementation for managing different types of bank accounts with various operations and account types.

## Features

- **Account Management**: Create and manage different types of bank accounts
- **Deposit**: Add money to your account
- **Withdrawal**: Withdraw money with account-specific rules
- **Balance Inquiry**: Check your current balance
- **Account Details**: View comprehensive account information
- **Account Types**: Support for Saving and Current accounts
- **Interest Calculation**: Automatic interest calculation for saving accounts
- **Access Control**: Private balance attribute for security

# ATM System

A simple ATM (Automated Teller Machine) system implementation in Python that allows users to perform basic banking operations.

## Features

- **Withdrawal**: Withdraw money from your account
- **Balance Inquiry**: Check your current account balance
- **PIN Management**: Manage your ATM PIN
- **Help**: Get assistance with the system
- **Transaction Logging**: All transactions are recorded in a transaction history file
